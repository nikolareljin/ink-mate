# Roadmap

This is planned work, not a claim of completed capability.

## Phase 0 — prove the board

Identify PCB revision, package, flash/PSRAM, and sourced pin map. Bring up every peripheral independently. Complete USB/battery reset matrices, display ghosting characterization, and battery measurement. OTA/deep sleep remain off.

## Phase 1 — local companion

Deliver provisioning/pairing, home/offline cards, push-to-talk, local faster-whisper + Ollama/`ai-runner` + Piper, concise answer/audio output, retries, redacted logs, and read-only model/host/repository/HTTP status cards.

## Phase 2 — safe tools

Add typed proposals, fixed templates, physical confirmation, expiry/replay protection, auditing, and workspace restrictions. Add disabled-by-default Codex/Claude job adapters. Enable OTA/rollback and power modes only for hardware revisions with passing evidence.

Later candidates include localization, calendar/task cards, signed configuration, multi-device management, TLS/device certificates, hardware-in-the-loop CI, and additional board profiles. Touch is a separate target.
